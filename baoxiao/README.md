# Invoice Email Downloader

从 POP3 邮箱下载指定时间范围内的发票附件，解压 ZIP，分类 PDF，并生成结构化 Excel 汇总。

## 安装

```bash
pip install -r requirements.txt
```

依赖包括 `python-dotenv`、`PyMuPDF` 和 `openpyxl`。

## 配置

在目录中创建 `.env`：

```env
POP3_SERVER=pop.126.com
POP3_PORT=995
EMAIL_USER=your_email@126.com
EMAIL_AUTH_CODE=your_authorization_code
```

## 使用

### Streamlit 页面（推荐）

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

浏览器页面包含两种模式：

- `邮箱下载并处理`：选择开始/结束日期和输出目录，从 `.env` 配置的邮箱下载、分类并生成 Excel。
- `本地文件夹处理`：填写现有 PDF 文件夹和输出目录；程序复制文件后再分类，不会移动或删除原始 PDF。

### 命令行

```bash
python invoice_downloader.py --start "2026-07-01" --end "2026-07-31" --raw-dir "./tem" --classify-dir "./发票" --taxi-template "./出租车报销单模板.xlsx"
```

## 分类与目录

- `高铁票/`：铁路电子客票，使用 `train_ticket.py` 提取日期、行程、金额和发票号。
- `出租票/`：出租车或网约车电子发票。
- `住宿票/`：住宿、酒店、宾馆、客房等发票。
- `其他发票/`：未归入前三类的一般发票。
- `行程单/`：与出租票配套的行程单，独立保存。
- `非发票/`：无法确认是铁路客票、普通电子发票或行程单的 PDF，例如报价函。

程序先识别铁路电子客票、普通电子发票和行程单三种文档类型，再对普通电子发票细分为出租、住宿和其他发票。普通 PDF 不会再兜底混入“其他发票”。

出租票本身没有可靠的乘车日期和路线时，程序会从匹配的行程单补充，并读取行程单中的每一段行程。未匹配的文件会打印警告，不会把开票日期冒充乘车日期，也不会编造路线。

## Excel

分类目录下生成 `发票.xlsx`，包含合并统计页和四个分类工作表：

| 工作表 | 字段 |
|---|---|
| 合并统计 | 分类张数、分类金额、总费用，以及所有发票统一明细 |
| 高铁票 | 日期、行程、金额、发票号、文件名 |
| 出租票 | 日期、行程、金额、发票号、文件名 |
| 住宿票 | 日期、酒店、金额、发票号、文件名 |
| 其他发票 | 日期、种类、金额、发票号、文件名 |

`合并统计` 位于第一张，分类小计和总费用使用 Excel 公式；高铁票工作表按乘车月份分块显示并计算分块小计。金额写为数值。

存在出租票时，还会基于 `出租车报销单模板.xlsx` 生成 `出租车报销单.xlsx`。匹配行程单的每段行程分别填写日期、起点、终点和票额；一张发票包含多段行程时只计算一张票据。超过 12 行会自动分页到多个工作表。姓名、部门和出差事由因来源中没有可靠数据，保留为空。

## 注意事项

- 邮箱必须开启 POP3，并使用邮箱授权码。
- 扫描版、图片版或没有文本层的 PDF 暂时无法可靠解析，需要先做 OCR。
- 文件名冲突时会自动增加数字后缀。
- `非发票/` 中的文件不会进入 `发票.xlsx`。

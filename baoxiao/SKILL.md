# 发票邮件下载与分类

## 执行流程

1. 读取 `.env` 中的 POP3 配置。
2. 按 `--start` 和 `--end` 筛选邮件日期。
3. 下载 PDF、ZIP 及邮件附件，自动解压 ZIP。
4. 识别两种票面：铁路电子客票、一般电子发票/行程单。
5. 将文件整理到六个目录：`高铁票/`、`出租票/`、`住宿票/`、`其他发票/`、`行程单/`、`非发票/`。
6. 将出租票与行程单配对；出租票 Excel 的日期和行程必须优先取对应行程单。
7. 在分类目录生成 `发票.xlsx`。
8. 存在出租票时，使用 `出租车报销单模板.xlsx` 生成 `出租车报销单.xlsx`。

## 使用命令

Streamlit 页面：

```bash
streamlit run app.py
```

页面提供“邮箱下载并处理”和“本地文件夹处理”两种模式。本地模式复制源 PDF 后再分类，不移动源文件。

```bash
pip install -r requirements.txt
python invoice_downloader.py --start "2026-07-01" --end "2026-07-31" --raw-dir "./tem" --classify-dir "./发票"
```

## 环境变量

```env
POP3_SERVER=pop.126.com
POP3_PORT=995
EMAIL_USER=your_email@126.com
EMAIL_AUTH_CODE=your_authorization_code
```

## 分类规则

- 将包含 `铁路电子客票` 的 PDF 分类为 `高铁票`，字段解析复用 `train_ticket.py`。
- 将网约车、出租车、滴滴、运输服务等一般发票分类为 `出租票`。
- 将包含住宿、酒店、宾馆、客房、房费等内容的一般发票分类为 `住宿票`。
- 将行程单、行程明细、网约车行程分类到独立的 `行程单` 文件夹，不作为 Excel 的第五类。
- 将其余一般电子发票分类为 `其他发票`。
- 未识别为铁路电子客票、普通电子发票或行程单的 PDF 分类为 `非发票`，不进入 Excel 汇总。
- 分类优先级为：高铁票、行程单、普通发票票面确认、普通发票内部分类、非发票。

## 出租票配对

- 分别保留出租票 PDF 和行程单 PDF，不合并文件。
- 优先按共同文件名标识、相同金额、相同日期匹配。
- 匹配成功后，用行程单补充出租票的 `日期` 和 `行程`。
- 行程单包含多段行程时逐段提取日期、起点、终点和金额，并逐行填写出租车报销单。
- 未匹配时保留出租票并打印警告，禁止凭空填写日期或行程。

## Excel 结构

生成一个工作簿，包含一个合并统计页和四个分类工作表：

- `合并统计`：四类发票张数、分类金额、总费用和全部发票统一明细
- `高铁票`：日期、行程、金额、发票号、文件名
- `出租票`：日期、行程、金额、发票号、文件名
- `住宿票`：日期、酒店、金额、发票号、文件名
- `其他发票`：日期、种类、金额、发票号、文件名

`高铁票` 按乘车月份分块并显示每月小计。`住宿票` 和 `其他发票` 保持上述字段结构。

金额写为数值。无法识别的发票号写为 `未识别`，无法可靠识别的其他字段留空或写为 `未识别`。

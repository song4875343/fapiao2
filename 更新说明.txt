发票打印工具 v3.2 更新说明
================================

更新内容：
---------
1. ✨ 新增帮助功能
   - 在工具栏"清空全部"按钮后面添加了"❓ 帮助"按钮
   - 点击后在主操作区域显示完整的使用帮助文档
   - 帮助内容包括：
     * 快速开始指南
     * 核心功能介绍（8大功能模块）
     * 详细操作指南（5个主要功能的使用方法）
     * 快捷键说明
     * 常见问题解答
     * 使用建议和最佳实践

2. 🎨 界面优化
   - 帮助页面采用现代化卡片式设计
   - 使用渐变色背景和阴影效果
   - 清晰的分区和排版，便于快速查找信息

3. 📝 文档更新
   - 更新了 README.md，添加帮助功能说明
   - 创建了独立的 help.html 文件（可单独打开查看）
   - 帮助内容也嵌入到 ui.py 中，确保在应用内正常显示

使用方法：
---------
1. 运行程序：python pdfm_v3.py
2. 点击工具栏的"❓ 帮助"按钮
3. 在主操作区域查看完整的帮助文档
4. 点击"< 返回编辑"按钮返回工作台

技术说明：
---------
- 帮助内容直接嵌入到 ui.py 的 HTML 中，不依赖外部文件加载
- 使用 CSS Grid 布局实现响应式卡片网格
- 采用渐变色和现代化设计风格，与主界面风格统一
- 支持滚动浏览，内容完整且易于导航

文件变更：
---------
- ui.py：添加帮助视图的 HTML 和 CSS，添加 showHelp() 函数
- help.html：创建独立的帮助文档（可选，也可单独打开）
- README.md：更新功能说明和版本日志
- 更新说明.txt：本文件

注意事项：
---------
- 如果帮助页面显示空白，请确保 ui.py 文件已正确更新
- 帮助内容已直接嵌入 HTML，不需要额外的文件依赖
- 可以随时点击"< 返回编辑"按钮返回工作台
